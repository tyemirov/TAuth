Docker Compose demo

This page connects a plain HTML header to a local TAuth service running under Docker Compose. Sign in with Google, observe the authenticated profile state, and use the sign-out control to clear your session.

Current session

Google sign-in requests are exchanged with http://localhost:8082. The helper script provided by TAuth monitors /me and /auth/refresh to keep a valid browser session without storing tokens in localStorage.

Awaiting connection to the TAuth service…

How it works

  1. The frontend is served by the gHTTP container on port 8000.
  2. TAuth listens on port 8082, issuing HttpOnly session cookies scoped to localhost.
  3. The demo requests /auth/nonce before rendering the Google button and exchanges the returned credential via /auth/google.
  4. The embedded tauth.js helper refreshes sessions by calling /auth/refresh whenever a request returns 401.
  5. Clicking Sign out invokes /auth/logout and resets the profile snapshot below.
