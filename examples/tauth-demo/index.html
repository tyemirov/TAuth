Docker Compose demo

This page connects a native browser interface to a local TAuth service running under Docker Compose. Sign in with Google, observe the authenticated profile state, and use the sign-out control to clear your session.

Current session

Google sign-in requests are exchanged with http://localhost:8082. The helper script provided by TAuth monitors /auth/session and /auth/refresh to keep a valid browser session without storing tokens in localStorage.

Awaiting connection to the TAuth service…

How it works

  1. The frontend is served over http://localhost:8000.
  2. TAuth listens on port 8082, issuing HttpOnly session cookies scoped to localhost.
  3. The page requests /auth/nonce before rendering the Google button and exchanges the returned credential through /auth/google.
  4. The embedded tauth.js helper refreshes sessions through /auth/refresh whenever a protected request returns 401.
  5. Clicking Sign out invokes /auth/logout and resets the profile snapshot below.
